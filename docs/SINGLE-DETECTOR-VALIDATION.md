# Single production detector — validation, 2026-10-13

## Implemented
Local Privacy Guard 1.7.4 uses optimized spaCy NER and Regex as its sole text detector. Presidio/Nym runtime selection, optional installer and dependent comparison tools are removed from production. Legacy detector settings normalize in memory without rewriting saved configuration or mappings. Privacy Agent 0.2.7 requires this release. Requesty runtime and version 0.6.0 are unchanged.

Alternative detectors, their benchmark implementation and evidence remain on `archive/cpu-pii-evaluation-2026-10-13` in each repository.

## Automated checks
Native isolated suites passed: Local 118, Manager 42 and Requesty 79 Python tests (239 total), plus 7/8/19 Node test entries (34 total). The native test framework includes the adapters generated by normal plugin installation. Changed-text credential checks, Python parsing and whitespace checks passed.

A private 37,119-character context replay used 20 repetitions per scenario with no model calls:

| Scenario | p50 seconds | p95 seconds |
| --- | ---: | ---: |
| Unchanged context | 0.194 | 0.199 |
| Known context plus new message | 0.207 | 0.211 |
| New large text | 2.419 | 3.277 |

Shared development hardware; these are filter measurements, not general model latency guarantees.

## Native lifecycle and chat
The provided primary test instance at port 59022 underwent actual native uninstall of all three plugins and reinstall through the native installer: Requesty from Git, and the tested Local/Manager release ZIPs. Its central protection was restored. All 105 original protected files, including credentials, presets, profiles and mappings, were byte-verified unchanged.

The secondary test instance at port 59021 underwent native Local/Manager uninstall and reinstall. Its central manager was originally inactive and was not disabled for this test. All 81 original protected files were byte-verified unchanged.

A disposable protected profile on the secondary instance ran a real native chat with local Ollama `qwen2.5-coder:7b`. The model used the native response tool and returned the requested marker and the exact locally restored synthetic email fixture. Four instrumented inner model calls used local endpoints only; the known raw fixture appeared in none of the captured outgoing positional/keyword payloads. The temporary assertion exported counters only, blocked nonlocal endpoints and was removed afterwards. Test contexts and profile were removed.

A preliminary local `granite4:tiny-h` attempt produced plain text rather than valid native tool calls and exhausted Agent Zero's five-response retry limit. This is recorded as an unsuccessful model/protocol trial, not a passed chat. The Qwen first response was a greeting; the follow-up returned the exact requested values.

The native settings page exposes the fixed spaCy/Regex methods and no Presidio/Nym selector or installer. Its artificial email example was checked without saving user settings.

## Limits
No paid Requesty model request was made. This run establishes the local chat and tested text roundtrip, not an end-to-end cloud chat under the primary installation-wide Requesty route. Existing native routes and image/browser/tool boundaries are unchanged. Detection can miss identifying details. Source texts, credentials and reversible mappings are excluded from repository evidence and reports.

Release ZIPs were built from tested source commits `8fee5f656fe2e422ee144d266fcd2bb6124a1b02` (Local) and `cdb23fb4b97981a281626a13cbb9bcae8d1dc856` (Manager); later report-only commits do not change their runtime contents.
